# Third-party components used by the optional built-in AI

The optional built-in AI feature downloads these components only after the user
selects **Install built-in AI** in jamovi. They are stored in the user's cache
and are not bundled in the jmvReport module.

## llama.cpp

- Project: https://github.com/ggml-org/llama.cpp
- Version: b10516
- License: MIT
- Copyright: llama.cpp contributors

The downloaded archive is selected for the current operating system and CPU
architecture and is checked against a pinned SHA-256 digest before use.

## Qwen3.5 model and GGUF quantization

- Base model: Qwen/Qwen3.5-4B
- Quantized model: TheStageAI/Qwen3.5-4B-GGUF
- File: Qwen3.5-4B-M-TS-Q4_K_M.gguf
- Pinned revision: 3e0455024fadf0eee0cec0f910582de99aaae986
- License: Apache License 2.0

The model file is checked against its pinned size and SHA-256 digest before use.
Model outputs may be inaccurate and must be reviewed by the user. Statistical
values in jmvReport remain generated by deterministic code and are verified
before AI-reworded text is accepted.
